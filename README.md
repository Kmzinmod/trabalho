# 🎶 Samba - Patrimônio Cultural Brasileiro

## Sobre o Projeto

Este é um trabalho escolar sobre o Samba, uma das maiores manifestações culturais do Brasil. O site apresenta informações sobre a origem, características musicais e como dançar samba.

## 📋 Conteúdo

- **Origem do Samba**: História e reconhecimento pela UNESCO
- **Características da Música**: Compassos, ritmo e instrumentos
- **Como Dançar Samba**: Passos básicos e técnicas
- **Conclusão**: Importância cultural do samba
